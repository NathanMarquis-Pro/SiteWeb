# Prénom Nom — Portfolio

Site vitrine personnel développé avec Angular et hébergé sur GitHub Pages.

🔗 [Voir le site](https://nathanmarquis-pro.github.io/SiteWeb/)

## Stack technique

- **Frontend** — Angular 17+, TypeScript, SCSS
- **Icônes** — Tabler Icons
- **Déploiement** — GitHub Pages via angular-cli-ghpages

## Lancer le projet en local

### Prérequis

- Node.js 18+
- Angular CLI

```bash
npm install -g @angular/cli
```

### Installation

```bash
git clone https://github.com/ton-pseudo/nom-du-repo.git
cd nom-du-repo
npm install
```

### Développement

```bash
ng serve
```

L'application sera accessible sur `http://localhost:4200`.

### Build

```bash
ng build --configuration production
```

### Déploiement

```bash
npm run deploy
```

## Structure du projet

```
src/

│   └── components/      # Composants Angular

```
